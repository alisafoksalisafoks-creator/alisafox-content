# Бот YouGile AlisaFox

Telegram-бот для владельца: кто чем занимался в YouGile за любой день, итоги компании, просрочки, постановка задач и сообщения в чаты словами или голосом. Компания в YouGile — «ИП Попова».

## Кнопки

- **📅 По дате** → календарь → сотрудники кнопками (цифра — сколько действий за день) → сотрудник → **📊 План|Факт**:
  - план: задачи со сроком на этот день и хвосты с прошлых дней, что выполнено;
  - факт: действия на досках (создал, перенёс в колонку, выполнил, переименовал, файлы, сроки), чаты задач, групповые чаты.
  План|Факт сначала приходит коротким конспектом (Claude), полный разбор — по кнопке «📋 Подробно». Без ключа Claude — сразу подробно.
  Сотрудники — все пользователи компании, кроме `YG_EXCLUDE` (Алина, Вера, Яна, Лана, Дана, Андрей, Менеджер, Дарина, Константин). Новый человек в YouGile появится сам.
- **✍️ Ввод** — просьба своими словами или голосовым: «поставь Веронике задачу обновить инфографику OZ565 до пятницы», «напиши в чат руководство, отметь Константина: созвон завтра в 11», «в задаче „Поставки“ напиши Анне: проверь транзит». Бот показывает план и делает только после «✅ Выполнить».
- **🏢 Итоги дня** — короткий конспект: итог дня и строка на каждого, кто работал. «📋 Подробно» — счётчики и главные задачи.
- **👤 Личный** — поставить задачу кнопками, «Поставлены мной, открытые» по исполнителям, «Мои задачи», «Мои действия сегодня».
- **💬 Чаты** — кнопки групповых чатов и людей → текст (отметка через @Имя) → «Отправить». Лично: API YouGile не даёт личные сообщения, поэтому бот один раз создаёт чат на двоих «Личное: Имя» и пишет туда. При выборе чата бот показывает последние сообщения, а ответы в чатах, куда вы писали через бота, сам не присылает: они собираются в кнопке **🔔 Новое в чатах** (с прошлого просмотра) с кнопками «↩️ Ответить» и «🔕 Не следить» (нужны события YouGile).
- **📈 Неделя** — эта или прошлая неделя по каждому: выполнено, создано, сообщений, всего, просрочено сейчас.
- **👥 Доступ** (только владелец) — человек пишет боту /start, вам приходит «👁 Только отчёты / ✅ Полный / ❌ Отказать». Полный доступ — «Ввод», «Личный», постановка задач.

Сам присылает (владельцу и всем с полным доступом), по рабочим дням `YG_WORKDAYS`:
- в 09:00 — итоги прошлого рабочего дня, просрочки, по понедельникам — прошлую неделю;
- в 11:00 — кто из сотрудников ещё ничего не сделал в YouGile (только когда включены события YouGile).

## Что бот видит и чего нет

- Входить в YouGile каждому не нужно: бот работает через один API-ключ администратора. Задачи и сообщения от бота YouGile покажет от имени владельца ключа.
- Действия видны с момента запуска бота через события YouGile (вебхуки). За дни до запуска бот собирает историю по задачам сотрудника — часть переносов и сообщений может не попасть, в отчёте будет пометка.
- **Личные переписки YouGile бот не видит и писать в личку не может**: API YouGile их не отдаёт. Вместо лички — чат задачи или групповой чат.
- Лимит YouGile — 50 запросов в минуту на всю компанию. Бот берёт не больше 30 (`YG_RPM`) и кеширует списки, чтобы не мешать работе людей.
- Сотрудникам стоит сказать, что работа в YouGile попадает в ежедневные отчёты: это рабочая система, но прозрачность сохраняет доверие.

## Установка на сервер Timeweb «AlisaFox»

Панель Timeweb → сервер «AlisaFox» → «Консоль», вход под root.

1. Новый бот у @BotFather → /newbot → скопировать токен.
2. Установка:
   ```
   git clone -b claude/project-thread-nl3oqt git@github.com:alisafoksalisafoks-creator/alisafox-content.git /opt/yougile-bot ; bash /opt/yougile-bot/yougile_bot/deploy/install.sh
   ```
   Скрипт создаст `/opt/yougile-bot/.env`, сам впишет адрес для событий YouGile (и ключ Claude, если он есть у бота «Промт инженер»), и остановится.
   Ключ Claude для «Ввода» и конспектов: console.anthropic.com → Billing (пополнить) → API Keys → Create Key, затем на сервере:
   `read -p "Ключ: " T && sed -i "s|^ANTHROPIC_API_KEY=.*|ANTHROPIC_API_KEY=$T|" /opt/yougile-bot/.env`
3. Ключ YouGile (логин и пароль администратора «ИП Попова» вводятся только на сервере, ключ сразу пишется в `.env`):
   ```
   /opt/yougile-bot/.venv/bin/python /opt/yougile-bot/yougile_bot/deploy/make_key.py
   ```
4. Токен бота: `nano /opt/yougile-bot/.env` → `TELEGRAM_YOUGILE_BOT_TOKEN=…` → Ctrl+O, Enter, Ctrl+X.
5. Ещё раз `bash /opt/yougile-bot/yougile_bot/deploy/install.sh` → должно быть «yougile-bot: active». Напишите боту /start.

Ключи в чат не присылайте — только в `.env` на сервере.

## Первая проверка после запуска

- В журнале появятся первые события YouGile: `journalctl -u yougile-bot -n 100 --no-pager | grep вебхук`. Если их нет 10 минут при работе людей — проверить, открыт ли порт 8090 у сервера в панели Timeweb (сеть/файрвол).
- Отправить через «Ввод» тестовое сообщение с отметкой себя в любой чат и проверить, что отметка сработала (формат упоминания `[!mention:id!]` сверяем на первом сообщении).

## Команды

- Обновить: `bash /opt/yougile-bot/yougile_bot/deploy/update.sh`
- Журнал: `journalctl -u yougile-bot -n 50 --no-pager`
- Все боты: `systemctl is-active supply-bot alisafox-bot promt-bot yougile-bot`

## Настройки (`.env`)

`YG_EXCLUDE` — кого не показывать кнопками; `YG_MORNING`, `YG_IDLE_CHECK`, `YG_WORKDAYS` — расписание; `YG_TZ` — часовой пояс (по умолчанию Екатеринбург, как в YouGile); `YG_WHISPER_MODEL` — качество голоса. Куда ставить задачу каждому сотруднику по умолчанию (доска и колонка) — `yougile_bot/employees.json`; кого там нет, получает задачу без доски.
