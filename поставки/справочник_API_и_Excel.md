# Поставки справочник: методы API и шаблоны Excel
Проверено 11.10.2026 ключом Ozon Seller API (только чтение). Ключи — только в настройках среды , не выводить и не сохранять.

## 1. Ozon Seller API — рабочие методы
| Задача | Метод | Что берём |
|---|---|---|
| Остатки по складам и кластерам | POST /v1/analytics/stocks (skus) | available_stock_count, transit_stock_count, requested_stock_count, inbound_replenishment, брак (transit/stock_defect), возвраты, excess_stock_count, ads и ads_cluster (продажи в день), idc и idc_cluster (дней хватит), turnover_grade(_cluster), days_without_sales, cluster_name, warehouse_name, placement_zone |
| Оборачиваемость по SKU | POST /v1/analytics/turnover/stocks | current_stock, ads, idc, turnover (дни), idc_grade, turnover_grade |
| Остатки FBO/FBS по товару | POST /v4/product/info/stocks | остаток по типу склада |
| Остатки по складам (старый) | POST /v2/analytics/stock_on_warehouses | для сверки |
| Склады FBS | POST /v2/warehouse/list | наши склады, график |
| Кластеры и склады Ozon | POST /v1/cluster/list, /v1/warehouse/fbo/list | id кластеров, склады для поставки, кросс-док |
| Продажи по кластерам | POST /v2/posting/fbo/list (with analytics_data, financial_data) | дата, город, кластер, SKU, количество |
| Поставки: список | POST /v3/supply-order/list | id заявок по статусам |
| Поставки: счётчик | POST /v1/supply-order/status/counter | сколько в каждом статусе |
| Поставка: карточка | POST /v3/supply-order/get | статус, склад сдачи и хранения, кросс-док, таймслот, теги (маркировка, ЭТТН, ЭВСД, УПД), bundle_id |
| Поставка: состав | POST /v1/supply-order/bundle (bundle_ids) | sku, offer_id, quantity, quant, volume_in_litres, barcode, placement_zone, sfbo_attribute (Super FBO), shipment_type |
| Грузоместа | POST /v1/cargoes/get (supply_ids) | cargo_id, type (BOX/палета), content_type (MONO/MIX), placement_zone_type, tracking_info (дата и статус прибытия/приёмки) |
| Возвраты и отмены | POST /v1/returns/list | возвраты на наш склад |
| Начисления | /v2/finance/realization, /v1/finance/cash-flow-statement/list | приёмка, логистика, хранение по факту |
Особенности (проверено 13.10.2026):
- /v2/posting/fbo/list: offset ограничен (MAX_OFFSET_EXCEEDED на ~20 тыс.) — выгружай по одному дню. cluster_to в financial_data — кластер покупателя, cluster_from — кластер отгрузки, analytics_data.warehouse_name — склад отгрузки.
- /v1/analytics/turnover/stocks: жёсткий лимит частоты; фильтр по skus даёт 429 — бери без фильтра, limit 1000, пауза между страницами.
- /v1/analytics/stocks: transit_stock_count + requested_stock_count = «в пути» из отчёта «Остатки». Состав заявок в статусе ACCEPTANCE_AT_STORAGE_WAREHOUSE не прибавлять — товар уже в available_stock_count.
- /v1/warehouse/fbo/list: search от 4 символов, отдаёт пункты сдачи и кросс-доки, не склады хранения. Выбор склада хранения при кросс-доке — только через черновик поставки (нужен ключ записи) или в кабинете.
- /v3/supply-order/get у завершённых поставок не отдаёт storage_warehouse — кластер бери из macrolocal_cluster_id.
- /v1/cluster/list (cluster_type CLUSTER_TYPE_OZON) — кластеры с macrolocal_cluster_id и складами.
Не работают: /v2/supply-order/*, /v2/fbs/posting/list, /v1/warehouse/list (устарел), /v3–v4 finance/transaction/*. Акта приёмки отдельным методом нет — акт качает владелец из кабинета.
Нужен отдельно ключ с правами записи: бронирование слотов, создание поставок, обновление остатков FBS (/v2/products/stocks). Методы записи вызывать только после «да» владельца на конкретный план.

## 2. WB, Яндекс Маркет, «Мой склад»
Пока без API. Когда дадут ключи: проверить методы остатков, поставок, складов, оборачиваемости и дописать сюда. Нужные домены добавить в «Разрешённые домены» среды: *.wildberries.ru, api.partner.market.yandex.ru, api.moysklad.ru.

## 3. Шаблоны Excel
### 3.1 Расчёт поставки (один файл, листы)
Лист «Распределительный лист» — ровно 4 колонки:
| Артикул | Склад (кластер) | Количество | Дата отгрузки |

Лист «Упаковочный лист»:
| № поставки | Склад | Грузоместо № | Тип (короб/палета) | Моно/микс | Зона размещения | Артикул | Штрихкод | Кол-во в месте | Итого мест |

Лист «Расчёт» (для проверки каждой цифры):
| Артикул | Модель (для дублей) | Склад/кластер | Продажи 28 дн | Дней в наличии | Скорость, шт/день | Скорость Ozon (ads) | Доступно FBO | В пути | В заявках | Дней запаса | Оборачиваемость FBO | Срок доставки, дн | Потребность | Округлено до короба | Остаток «Мой склад» | Статус из таблицы | Рейтинг | Дата платного хранения | Итог |

Лист «Решить / стоп»:
| Артикул | Склад | Причина (статус / рейтинг < 4,6 / оборачиваемость > 45 / запас > 70 / скоро платное / дубль / новинка) | Цифры | Рекомендация | Решение владельца |

Лист «К закупке»: | Артикул | Не хватает, шт | Поставщик (Китай/Россия) | Когда заказать |
