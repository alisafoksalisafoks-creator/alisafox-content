# Поставки

Обезличенная инструкция отдела логистики и подсорта для маркетплейсов (Ozon, Wildberries, Яндекс Маркет): скорость продаж, запас не больше 30 дней по кластерам, стоп-лист, отчёт «FBO + FBS», прогноз платного хранения, новинки, распределительные и упаковочные листы, сверка поставок, приёмки, актов и остатков.

- `инструкция_короткая.md` — для поля «Инструкция» проекта (около 9 тыс. знаков)
- `инструкция_полная.md` — модули П1–П14 с формулами
- `справочник_API_и_Excel.md` — методы Ozon Seller API и шаблоны Excel
- `чек_листы.md` — чек-листы поставки и приёмки, шаблоны обращений в поддержку

Цифры магазина, артикулы и график отгрузок убраны: в тексте стоят условные ART… и [N], [K], [дни].
