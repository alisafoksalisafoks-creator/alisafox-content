# РНП AlisaFox: кнопки «График товара» и «Остатки»

Файл скрипта: `ГрафикиОстатки.gs`. Таблица: «РНП AlisaFox».

## Установка (2 минуты)
1. Таблица → Расширения → Apps Script.
2. Слева «+» → «Скрипт» → назвать `ГрафикиОстатки` → вставить весь текст файла → сохранить (Ctrl+S).
3. В вашем существующем файле найти `function onOpen()` и первой строкой внутри добавить:
   `rnpAddMenu();`
   (если onOpen нет — создать: `function onOpen(){ rnpAddMenu(); }`)
4. Обновить таблицу (F5). Появится меню «📈 Графики».
5. Первый раз: «📈 Графики» → «Включить ежедневный снимок остатков» → разрешить доступ.
   Если скрипт скажет, что нет ключей: «Ключи Ozon для остатков» → ввести Client-Id и Api-Key.

## Откуда данные
- График: лист «РНП» (заказы, цена, место, ДРР, клики, показы, прибыль на 1 шт, остаток FBO) и «API Общий ДРР» (реклама ₽, сумма заказов).
- Акции: Ozon Seller API `/v1/actions` + `/v1/actions/products` (текущие), история — из снимков.
- Остатки: Ozon Seller API `/v4/product/info/stocks` (FBO/FBS) и `/v1/analytics/stocks` (кластеры, продажи в день). История по кластерам — лист «API Остатки кластеры», одна строка на SKU в день.
