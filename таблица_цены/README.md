# Цена клиента в таблице цен (Ozon, ЯМ, WB)

Скрипт `ЦенаКлиента.gs` заполняет колонки «Цена клиента Ozon / ЯМ / WB» по артикулу площадки в строке.

| Площадка | Что пишем | Откуда (API) |
|---|---|---|
| Ozon | цена на сайте | `/v5/product/info/prices` → `marketing_price` (если пусто → `marketing_seller_price` → `price`) |
| Яндекс Маркет | цена на витрине | `/v2/campaigns/{id}/offer-prices` → `price.value` |
| Wildberries | цена со скидкой (без кошелька ВБ и без СПП) | `/api/v2/list/goods/filter` → `sizes[].discountedPrice` (минимум по размерам) |

Артикул в строке может быть любым из: Ozon — offer_id, product_id, SKU; ЯМ — ваш SKU (offerId) или SKU на Маркете; WB — nmID или артикул продавца.

## Правила
- Колонки ищутся по названию в шапке (первые 15 строк), не по букве. Удаление и перестановка столбцов скрипт не ломают.
- Пишем во все строки, включая скрытые и отфильтрованные.
- Пустые строки без артикула не трогаем.
- Ключи API хранятся в «Свойствах скрипта», не в коде.
- Меню ставится отдельным триггером и не конфликтует с существующим `onOpen`.

## Установка (5 минут)
1. Таблица → **Расширения → Apps Script** → слева «+» → **Скрипт** → назвать `ЦенаКлиента`.
2. Вставить весь код из `ЦенаКлиента.gs` → 💾 Сохранить.
3. Вверху выбрать функцию **cpInstall** → ▶ **Выполнить** → разрешить доступ.
4. В таблице появится меню **💰 Цены клиента** → ⚙️ Настройки → ввести ключи → «Проверить ключи».
5. Нажать «🔄 Ozon / ЯМ / WB».

Если колонка артикула называется иначе, допишите её название в `CP.KEY_HEADERS` в начале кода.
