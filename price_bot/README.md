# Бот «Цены AlisaFox» (Ozon)

Telegram-бот для цен и скидки от количества на Ozon. Всё по кнопкам, ничего не меняет в Ozon без «✅ Да, применить».

## Что умеет

В боте только товары в продаже с остатком на складах Ozon (FBO); в списке артикулов — только артикул и остаток FBO.

**💰 Цены** → категория → артикул → дашборд на одном экране:
- остатки FBO и FBS, текущая цена, цена с вашими акциями и цена на сайте;
- вилка акции «Эластичный бустинг» (колонки AY/AZ шаблона цен): «снизьте на 14 ₽ — попадёте в акцию», «снизьте на 144 ₽ — макс. бустинг»;
- ЧП на 1 шт за 10 дней, ДРР общий и РК ДРР — из TrueStats;
- соинвест сегодня и ▲/▼ к вчера: (цена с вашими акциями − цена на сайте) / цена с вашими акциями;
- текущая скидка от количества;
- среднее место в выдаче и ▲/▼ к вчера.

Кнопки: **✏️ Изменить цену** → ввод цены → «было → стало», прогноз ЧП и ДРР, предупреждения → «✅ Да, применить». **✅ Оставить**, **⬅️ Назад**.

**📦 Скидка от количества** → категория → артикул или «Вся категория» → редактор уровней. Редактор берёт текущие уровни из Ozon и показывает «Сейчас в Ozon» и «Будет после сохранения». У каждого уровня кнопки **−1% / +1% / ✏️ / 🗑**, ниже **➕ Добавить уровень** (сначала «от скольких штук», потом «какая скидка», кнопками или числом) и **🗑 Убрать все**. **✅ Сохранить** → «было → стало» по каждому товару → «Да, применить». До 4 уровней, только в %, скидка растёт с количеством. Через минуту бот проверяет, применил ли Ozon.

**📜 История** — последние 15 изменений через бота (кто, когда, на сколько) и кнопка «📥 Скачать за месяц (Excel)» со всеми изменениями за 30 дней. **🔄 Обновить остатки** — перечитать из Ozon список товаров в продаже с остатком FBO. Сам бот список не обновляет, только по этой кнопке. **👥 Доступ** — только владельцу, как в промпт-боте.

### Откуда цифры
| Что | Источник |
|---|---|
| Цена, мин. цена, комиссия | Ozon `/v5/product/info/prices` |
| Цена на сайте, соинвест | Ozon `/v2/actions/products` и `/v2/actions/candidates`, поле `website_prices` (без подписки); соинвест ≈ (цена с вашими акциями − цена на сайте) / цена с вашими акциями |
| Вилка бустинга AY/AZ | Ozon `/v2/actions/products` и `/v2/actions/candidates`, поля `price_min_elastic` / `price_max_elastic` |
| Скидка от количества | Ozon `/v1/product/stairway-discount/by-quantity/get` и `/set` (бета-методы Ozon) |
| Место в выдаче | Ozon `/v1/analytics/data`, метрика `position_category` |
| ЧП на 1 шт, ДРР, РК ДРР | TrueStats, отчёт по товарам: `averageProfitPerPiece`, `drr`, `drrz` |

Прогноз ЧП при новой цене: `ЧП + (новая − текущая) × (1 − комиссия Ozon − общий ДРР) × (1 − 7% УСН)`. Это оценка, не факт.

«Вчера» для соинвеста и места в выдаче бот берёт из своих снимков (каждые 3 часа). Сравнение появится на второй день после запуска.

## Установка на сервер Timeweb «AlisaFox»

1. В @BotFather создайте нового бота (/newbot), скопируйте токен.
2. Панель Timeweb → сервер «AlisaFox» → «Консоль», вход под root. Вставить и нажать Enter (скачивание идёт ключом бота поставок: у root своего доступа к GitHub нет):

```
GIT_SSH_COMMAND="ssh -i /opt/supply-bot/.ssh/id_ed25519" git clone -b claude/project-thread-xqdb0s git@github.com:alisafoksalisafoks-creator/alisafox-content.git /opt/price-bot && bash /opt/price-bot/price_bot/deploy/install.sh
```

3. Скрипт по очереди спросит ключи: токен бота, Ozon Client ID, Ozon API-ключ, адрес и ключ TrueStats (их можно пропустить Enter). Вставить — правая кнопка мыши, потом Enter. На экране ключи не видны, так и задумано. Поменять ключ потом: `nano /opt/price-bot/.env`.

Должно появиться «price-bot: active».

## Команды

- Обновить после правок: `bash /opt/price-bot/price_bot/deploy/update.sh`
- Проверить все боты: `systemctl is-active supply-bot alisafox-bot promt-bot price-bot`
- Журнал: `journalctl -u price-bot -n 50 --no-pager`
- История изменений — кнопка «📜 История» в боте (файл `/var/lib/price-bot/history.jsonl`)

## Файлы

Код: `/opt/price-bot`, ключи: `/opt/price-bot/.env`, данные (доступы, каталог, снимки, история изменений): `/var/lib/price-bot`.
