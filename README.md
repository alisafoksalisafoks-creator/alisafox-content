# alisafox-content

Правила маркетплейсов и инструкции для проектов магазина AlisaFox (Ozon, Wildberries, Яндекс Маркет).

Это **публичная обезличенная копия**. Здесь нет цифр магазина, реальных артикулов (вместо них условные ART…), хитов, номеров документов, адресов и города склада. Полные версии лежат в файлах проектов и на Google Диске в папке «AlisaFox — инструкции».

## Карта папок

```
правила/                     правила площадок, общие для всех проектов
├── ozon_правила.md
├── wb_правила.md
├── яндекс_маркет_правила.md
├── README.md                журнал обновлений
├── карточки/                правила площадок про карточку, SEO и выдачу
└── контент/                 правила площадок про фото, инфографику, рич и видео

инструкции/                  по одной папке на каждый проект
├── аккаунт/                 общая инструкция для всего аккаунта
├── роп/                     «AlisaFox — РОП»: продажи, аналитика, юнит-экономика
├── карточки/                «Карточки»: SEO, атрибуты, перенос между площадками
├── контент/                 «Контент»: инфографика, рич, фото, видео + шаблоны/
├── сервис/                  «Отдел сервиса»: отзывы, вопросы, рейтинг, жалобы
├── поставки/                «Поставки»: FBO и FBS, подсорт, хранение
└── промпт_инженер/          «Промпт-инженер»: промпты, инструкции, боты
```

В каждой папке проекта:
- `инструкция_для_поля.md` — короткая версия, её вставляют в поле «Инструкция» проекта;
- `инструкция_полная.md` — полная методика, её кладут в файлы проекта;
- остальное — справочники, шаблоны и чек-листы этого проекта.

## Как папки обновляются

- Правила площадок обновляются по расписанию 1 и 15 числа каждого месяца и сохраняются в `правила/` (общие), `правила/карточки/` и `правила/контент/`.
- Когда в проекте меняется инструкция, её обезличенная копия заменяет файл в папке этого проекта в `инструкции/`.
- Новый проект — новая папка в `инструкции/` и строка в карте выше.
- Правило площадки главнее любой инструкции.
