# Поставки

Логистика и подсорт: скорость продаж, запас по кластерам, FBO и FBS, платное хранение, новинки, распределительные и упаковочные листы, сверка приёмок.

- `инструкция_для_поля.md` — для поля «Инструкция» проекта (около 9 тыс. знаков)
- `инструкция_полная.md` — модули П1–П14 с формулами
- `справочник_API_и_Excel.md` — методы Ozon Seller API и шаблоны Excel
- `чек_листы.md` — чек-листы поставки и приёмки, шаблоны обращений в поддержку

Количества, артикулы и график отгрузок условные: ART…, [N], [K], [дни].
