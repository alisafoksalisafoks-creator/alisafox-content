# Поставки чек-листы и шаблоны обращений
Версия 1 от 11.10.2026. Требования Ozon к грузоместам, маркировке и срокам претензий сверять в правила/ozon_правила.md; нет раздела — найти на docs.ozon.ru / seller-edu.ozon.ru и дописать.

## 1. Перед расчётом поставки
- [ ] Остатки FBO по складам и кластерам (API) на сегодня
- [ ] Остатки FBS и отправления FBS
- [ ] Поставки в пути и в заявках
- [ ] Продажи за 28 дней, дни без остатка учтены
- [ ] Таблица статусов площадки свежая (нет доступа — запросить выгрузку)
- [ ] Файл «Моего склада» за сегодня или вчера
- [ ] Рейтинг покупателей не старше 7 дней
- [ ] Новинки отмечены, стратегия первой поставки спрошена

## 2. Стоп-лист (по каждой строке)
- [ ] Статус «не грузим» → вычеркнуть
- [ ] Оборачиваемость FBO > 45 дн или запас FBO > 70 дн → не грузим
- [ ] Платное хранение ≤ 30 дн и не распродастся → «поставка не нужна»
- [ ] Рейтинг < 4,6 → «решить»
- [ ] Дубль с двумя «грузим» → спросить
- [ ] Запас после прибытия ≤ 30 дн
- [ ] Хочет грузить из стоп-листа → повторное предупреждение с цифрами и вопрос «вносить?»

## 3. Упаковочный лист
- [ ] Количество не больше остатка «Моего склада»
- [ ] Кратность короба / кванта соблюдена
- [ ] Моно- или микс-короб по требованиям склада и типа поставки
- [ ] Зона размещения совпадает с placement_zone товара
- [ ] Спецусловия: маркировка, ЭТТН/УПД — по тегам поставки
- [ ] Штрихкоды совпадают с карточками
- [ ] Итог мест и штук сходится с распределительным листом

## 4. Проверка созданной поставки (до отгрузки)
- [ ] Склад и тип: наш город — прямая; остальные — транзит/кросс-док
- [ ] Таймслот совпадает с днём отгрузки
- [ ] Состав = распределительный лист (артикул, штуки)
- [ ] Грузоместа: число, моно/микс, зоны
- [ ] Super-статус по позициям
- [ ] Стоимость приёмки и логистики посчитана по тарифу из базы знаний

## 5. После приёмки
- [ ] Отправлено = прибыло мест = принято штук
- [ ] Расхождение → владельцу: поставка, склад, артикул, шт, ₽ по себестоимости
- [ ] Запрошен акт приёмки/расхождений из кабинета
- [ ] Обращение в поддержку подготовлено, срок подачи проверен

## 6. Шаблон обращения в поддержку Ozon: расхождение при приёмке
Тема: Расхождение при приёмке поставки № [номер]
Здравствуйте! По поставке № [номер] на склад [склад], дата приёмки [дата], принято меньше, чем отправлено.
- Грузоместо [№]: артикул [артикул], штрихкод [..], отправлено [N] шт, принято [M] шт, разница [N−M] шт.
Доказательства: упаковочный лист, фото и видео сборки и опломбировки грузоместа, накладная, отметка о сдаче [дата].
Просим провести проверку и зачислить [N−M] шт на склад или возместить их стоимость по правилам площадки.
Отправляет команда или Claude после «да» владельца.

## 7. Шаблон обращения: товар не принят / брак при приёмке
Тема: Поставка № [номер]: [не принят / признан браком] артикул [артикул]
Здравствуйте! Артикул [артикул] в поставке № [номер] [не принят / помечен браком] на складе [склад]. Товар упакован по требованиям [ссылка на раздел правил], при сборке был целым — прикладываем фото и видео. Просим уточнить причину и пересмотреть решение.

## 8. Сверка «Мой склад» — учёт — площадка (раз в неделю)
- [ ] По каждому артикулу: Мой склад ↔ таблица движения ↔ отгружено и возвращено по API
- [ ] Расхождения > 0 шт в список с вероятной причиной
- [ ] Возвраты с площадки оприходованы
- [ ] Дубли артикулов (ART001 / ART001New) сведены по модели
