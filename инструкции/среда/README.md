# Облачная среда: домены и ключи API

Обезличенная копия. Полные версии — в файлах проекта и на Google Диске.

- `домены_API.md` — какие домены внесены в Allowed domains, для чего каждый, статус проверки и имена переменных среды (без значений).
- `подключение_МойСклад_TrueStats.md` — как подключали МойСклад и TrueStats: заголовки, где создать токен, как внести в среду.

Значения ключей и токенов здесь не хранятся и храниться не должны.
