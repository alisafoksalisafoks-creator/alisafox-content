# Таблица индекса цен Ozon

1. `python3 pull.py` (в пустой папке, нужны OZON_CLIENT_ID и OZON_API_KEY) — выгружает prices.json и info.json из Ozon Seller API.
2. Себестоимость — экспорт себестоимости TrueStats (Ozon, одна строка на артикул), файл costs.xlsx.
3. `python3 build.py <папка с json> costs.xlsx indeks-cen-ozon-ГГГГ-ММ-ДД.xlsx` — собирает таблицу: Сводка, Индекс цен, Новые цены, Как работать, Настройки.

Прибыль: (цена с акциями − комиссия FBO − логистика FBO − эквайринг − себестоимость) × (1 − УСН 7%). Рекомендованная цена — оценка: цена × целевой индекс / худший индекс. Цены в кабинете меняет команда.
