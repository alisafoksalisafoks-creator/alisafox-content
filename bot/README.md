# Бот аналитики AlisaFox

Telegram-бот: утренняя сводка по категориям и ответы по артикулам. Только читает API площадок, в кабинетах ничего не меняет.

ТЗ: https://claude.ai/artifact/2kdv2wXiLdVoAzb8AM2z6W

## Ключи (только переменные окружения, не в код)
- `OZON_CLIENT_ID`, `OZON_API_KEY` — Ozon Seller API
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — отправка в Telegram

## Сейчас готово
- `python -m bot.category_report [YYYY-MM-DD]` — сводка Ozon по типам товаров за день: заказы шт/₽, к вчера и к тому же дню недели, дни остатка (FBO+FBS свободный / средние заказы за 14 дней), SKU с остатком меньше 14 дней.

## Бот
- `python -m bot.app` — бот: меню «Категории», «Артикул», «Что подгрузить»; карточки за вчера/неделю/месяц с воронкой; `/compare АРТИКУЛ 01.10-15.10 01.09-15.09` — сравнение периодов.
- Доступ только для ID из `TELEGRAM_CHAT_ID`.
- История продаж хранится в `bot/data.sqlite` (первая загрузка 120 дней ~10 минут, дальше обновление каждое утро в 6:00 МСК).
- `bot/deploy/alisafox-bot.service` — служба systemd с автоперезапуском.

## Агент поставок Ozon FBO
- `python -m bot.supply --out план.xlsx` — план отгрузки на склады Ozon: по кластерам и артикулам, сколько везти со своего склада (МойСклад) и где своего не хватает, плюс перебор > 60 дней. Правила те же, что у кнопки «Поставки» (`restock.py`), сверху — срок доставки до приёмки и кратность коробов.
- `bot/supply_settings.json` — дни доставки до приёмки и целевой запас; `bot/supply_items.csv` — кратность коробов по артикулу (`article;box_qty`). Пустая кратность — штуки не округляются.
- Заказ поставщику не считается: решение о заказе — по чистой прибыли, отдельный бот.
