# Бот «Аналитик» AlisaFox (@audit_alisafox_bot)

Telegram-бот аналитики Ozon: утренняя сводка, карточки категорий и артикулов, сигналы по остаткам, прибыль, соинвест, цены и акции, TrueStats. Только читает API, в кабинетах ничего не меняет. Ответы — картинками-листами.

## Меню
- **📊 Сводка за вчера** — листы: главные цифры и категории, реклама и финансы, остатки и сигналы, рейтинг; последний лист — TrueStats за вчера к позавчера.
- **📦 Категории** → категория → карточка (вчера / неделя / месяц, топ-8, воронка) → кнопки артикулов с остатком FBO → карточка артикула.
- **🔎 Артикул** → карточка артикула. Под карточкой: **🚦 Сигналы**, **💰 Цены**.
- **💰 Цены** (в карточке артикула и в «Соинвесте»): цена, цена с вашими акциями и с картой на сайте, соинвест сейчас и за 7 дней, прибыль на 1 шт и ДРР за 2 недели, все акции с порогом входа (у бустинга — вход и макс. бустинг), на сколько снизить цену и прибыль на 1 шт при этой цене, скидка от количества. Логика порогов — как в боте «Цены» (`price_bot/`). Менять цену — только в боте «Цены».
- **🚦 Сигналы по остаткам** — пора отгрузить, пересорт, платное хранение, по артикулу. Скорость — заказы 14 дней с сезонностью (`bot/seasonality.json`). Штуки по кластерам считает бот поставок.
- **📍 Позиции**, **🔑 Ключи** — места в выдаче и поисковые запросы.
- **📉 Минусовые артикулы** — категории → артикулы в минусе за 14 дней (реализация, реклама по SKU, себестоимость +3%, УСН 7%).
- **🤝 Соинвест** → период (вчера к позавчера / 7 дней к прошлым 7) → категории или артикул.
- **📈 TrueStats** → вчера / неделя / свой период: 7 плиток «Общие показатели» (прибыль и маржинальность, продажи, заказы, выкуп, реклама и ДРР, средняя цена, возвраты) к прошлому такому же периоду.
- **🔕 Отменить пожелания** / **🔔 Вернуть пожелания** — каждый сам отключает утреннее приветствие, погоду и гороскоп.
- **👥 Пользователи** (только владелец) — доступ к боту.

## Правила
- Артикулы «ДБ…» — тестовые, исключены везде.
- Артикулы с остатком FBO меньше 1 шт не показываются ни в списках, ни в сигналах (`bot/stockfilter.py`); общие суммы не меняются.
- Себестоимость: МойСклад, при отсутствии — Google-таблица «Юнит экономика Алиса» (читается сервисным аккаунтом бота поставок, файл `costs_fallback.csv` в git не попадает).

## Утро, 9:00 МСК, каждый день
1. Приветствие по имени с комплиментом и пожеланием (`bot/greetings.py`).
2. Сводка листами + лист TrueStats.
3. Погода в городе и гороскоп по знаку (`bot/daily_extras.py`; Open-Meteo и ignio.com, без ключей). Кому и куда — файл `bot/people.txt` на сервере, строки `кто; город; ДД.ММ` (кто — Telegram ID, «я» или имя из «Пользователей»). Файл в git не попадает. Проверка: `cd /opt/alisafox-content && .venv/bin/python -m bot.daily_extras`.

## Ключи (только `/opt/alisafox-content/.env`, не в код и не в чат)
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (владелец), `OZON_BOT_CLIENT_ID` / `OZON_BOT_API_KEY` (свой ключ бота; иначе `OZON_CLIENT_ID` / `OZON_API_KEY`), `OZON_PERF_CLIENT_ID` / `OZON_PERF_CLIENT_SECRET`, `MOYSKLAD_TOKEN`, `TRUESTATS_TOKEN`, `HEALTHCHECK_URL` (необязательно).

## Сервер (Timeweb, общий с ботом поставок)
- Код: `/opt/alisafox-content`, ветка `claude/project-thread-eb5j0j`. Данные: `bot/data.sqlite`.
- Обновить: `bash /opt/alisafox-content/bot/deploy/update.sh` → «Обновлено до: …».
- Журнал: `journalctl -u alisafox-bot -n 50 --no-pager`.
- Служба `alisafox-bot` (`bot/deploy/alisafox-bot.service`): `Restart=always` — после сбоя перезапуск через 10 секунд; `WantedBy=multi-user.target` + `systemctl enable` — сама стартует после перезагрузки сервера.
