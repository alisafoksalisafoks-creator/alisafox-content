# Инструкция бот «Покупатели»

Версия от 27.10.2026. Паролей и ключей здесь нет и быть не должно. Они лежат только на сервере.

## Что делает бот

Следит за покупателями Ozon из списка (~15 ID): что купили, сколько штук, по какой цене. Показывает места в выдаче и поисковые запросы по купленным артикулам. Бот только читает Ozon, в кабинете ничего не меняет. Ответы — картинки-таблицы прямо в чате, без файлов.

ID покупателя — первая часть номера заказа: 47327265-0623-1 → покупатель 47327265.

## Главное меню

| Кнопка | Что показывает |
| :-- | :-- |
| 🛒 Выкупы сегодня | Кто из списка купил сегодня и сколько штук. Кто не покупал — строкой «Без покупок: N из M». |
| 👥 Покупатели | Список имён. Внутри: имя или «👥 Выкупы всего» → период → вид отчёта. |
| 📍 Места в выдаче | 7 дней или месяц: артикулы, которые купили покупатели из списка, по дням — место в выдаче. |
| ➕ Добавить ID покупателя | Прислать «47327265 Анна 1». Можно сразу несколько, каждого с новой строки. Можно номер заказа целиком. |
| ✏️ Редактировать | Имя → «Изменить имя» или «Удалить». Заказы в базе остаются. |
| 👤 Пользователи | Только у владельца: кто имеет доступ, закрыть доступ, добавить по Telegram ID. |

## Периоды

- **Сегодня** — заказы за сегодня.
- **7 дней** — 7 полных дней до вчера, без сегодняшнего.
- **Месяц** (кнопка с названием месяца) — с 1-го числа текущего месяца по сегодня.

## Виды отчёта после периода

- **🔢 Штуки** — только числа: по дням (у одного покупателя) или по именам (у «Выкупы всего»). Дни без покупок не показываются.
- **📋 Детали** — артикул, штуки, «В заказе» и «Заплатил».
  - «В заказе» — наша цена продажи в заказе Ozon.
  - «Заплатил» — цена для покупателя по данным Ozon, со скидками за счёт Ozon. «—» — Ozon эту цену не отдал.
- **👤 Имена** (только в «Выкупы всего») — список аккаунтов; по клику — итог покупателя за выбранный период: штуки, заказы, сумма в заказах и сколько заплатил.
- **🔑 Ключи** — для каждого купленного артикула топ-5 поисковых запросов по заказам и среднее место. Это запросы всех покупателей артикула по кабинету: Ozon не пишет в заказ, по какому запросу его нашли. Данные готовы только по позавчера.

## Места в выдаче

Средняя позиция артикула в поиске и каталоге Ozon за день: чем меньше, тем выше. Зелёная ячейка — поднялся к прошлому дню, красная — опустился, «—» — не показывался. Данные есть по вчера. Месяц режется по неделе на картинку.

## Правила подсчёта

- Считаем заказы (оформлен заказ), а не получение в ПВЗ.
- Отменённые заказы в итог не идут, пишутся отдельно «Отменено N шт.».
- Отзывы, их число и звёзды через API Ozon недоступны (нужна подписка Premium Plus).

## Доступ

Новый человек жмёт /start — владельцу приходит запрос с кнопками «✅ Открыть» / «❌ Отказать». Допущенные видят всех покупателей и могут добавлять и редактировать их. Пускать и убирать людей может только владелец.

## Сервер и команды

Сервер — тот же VPS Timeweb, что у остальных ботов. Папка /opt/buyers-bot, сервис buyers-bot. Ключ Ozon (только чтение) берётся из настроек «Аналитика».

Как зайти в консоль — см. документ «Боты — 1. Сервер, настройки и команды».

Обновить бота после правки Claude:

```
bash /opt/buyers-bot/buyers/deploy/update.sh
```

Установить заново (если сервер новый):

```
curl -fsSL https://raw.githubusercontent.com/alisafoksalisafoks-creator/alisafox-content/claude/project-thread-qarkfk/buyers/deploy/install.sh | bash
```

Установщик спросит токен бота из BotFather и Telegram ID владельца. После запуска ~5 минут бот загружает историю заказов за 40 дней.

Посмотреть журнал: `journalctl -u buyers-bot -f` (выйти: Ctrl+C). Перезапустить: `systemctl restart buyers-bot`.

## Как работает внутри

- Код: GitHub, репозиторий alisafox-content, ветка claude/project-thread-qarkfk, папка buyers/.
- Заказы FBO и FBS качаются в свою базу: первый раз за 40 дней, дальше каждые 10 минут; в 4:00 перепроверяются отмены за 10 дней.
- Цена «Заплатил»: у FBS — из списка заказов, у FBO — отдельным запросом по каждому заказу покупателей из списка.
- Ключи: Ozon «аналитика запросов» (до 15 запросов на артикул). Места: Ozon аналитика, метрика «средняя позиция».
